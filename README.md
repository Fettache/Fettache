## About Me

I am an Artificial Intelligence and Emerging Technologies student focused on building practical, end-to-end projects that connect data, software and connected devices.

My work combines Machine Learning, Deep Learning, IoT, cybersecurity, backend development and interactive dashboards. I enjoy turning technical ideas into working applications that can be tested, explained and improved.

Currently, I am especially interested in:

- IoT security and intrusion detection;
- Machine Learning and Deep Learning applied to real data;
- NLP and Computer Vision applications;
- backend APIs with Python and FastAPI;
- real-time dashboards with React and WebSocket;
- embedded systems with ESP32 and Arduino.
